# LRBrained Marketing Analytics Dashboard

An AI-powered, multi-platform marketing analytics dashboard built with **React** (frontend) and **Node.js + Express** (backend).  
The dashboard aggregates marketing data from websites and social media channels (Facebook, Instagram, LinkedIn, Google Analytics) and provides actionable insights using AI.

## Features

- ✅ **User Authentication**: Secure login and registration (JWT-based)
- 📊 **Dashboard Overview**: Key metrics, charts, and KPIs
- 🌐 **Website Analytics**: Traffic, sessions, top pages
- 📱 **Social Media Analytics**: Engagement, reach, follower growth
- 🤖 **AI Insights**: Auto-generated insights summarizing your marketing performance
- 💡 **Smart Recommendations**: AI-powered actionable suggestions
- ⚠️ **Alerts & Anomalies**: Detect drops or spikes in performance
- 💬 **Conversational Chatbot**: Ask questions about your marketing data
- 🎨 **Modern UI**: Clean and responsive interface (MagicPatterns + Tailwind CSS)

## Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express.js, OpenAI API for AI features
- **Database**: MongoDB
- **APIs**: Google Analytics API, Meta Graph API (Facebook & Instagram), LinkedIn API
- **Authentication**: JWT, OAuth
